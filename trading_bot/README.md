# Торговый бот: 6 ИИ-агентов для акций Мосбиржи

Бот сам анализирует российские акции и торгует ими. Решение принимает команда из 6 агентов,
по той же схеме, что в популярных роликах про «ИИ-хедж-фонд» (за основу взят открытый проект TradingAgents):

| # | Агент | Что делает |
|---|-------|-----------|
| 1 | Технический аналитик | Свечи и индикаторы: EMA, SMA200, RSI, MACD, Боллинджер, ATR |
| 2 | Новостной аналитик | Новости компании и рынка (ЦБ, ставка, рубль, нефть) из RSS Интерфакса и РБК |
| 3 | Аналитик поведения трейдеров | Лента сделок Мосбиржи (кто давит: покупатели или продавцы), крупные игроки, объёмы, индекс страха и жадности |
| 4 | Бык и Медведь | Спорят о сделке, судья выбирает победителя и даёт итоговый сигнал |
| 5 | Трейдер | Решение BUY / SELL / HOLD, размер, стоп-лосс, тейк-профит |
| 6 | Риск-менеджер | Последнее слово: урезает размер или запрещает сделку |

Каждый агент думает через **Claude**. Если ключа нет или API недоступен, агент
переключается на свой встроенный алгоритм, и бот продолжает работать.

## Как бот учится сам

1. **Точность агентов.** Каждый сигнал через 5 циклов сверяется с реальным движением цены.
   Агенты, которые чаще угадывают, получают больший вес в голосовании (от 0.5 до 1.5).
2. **Уроки сделок.** После закрытия позиции Claude разбирает сделку и записывает урок.
   Трейдер читает последние 10 уроков перед каждым решением.

Всё хранится в `data/memory.json` и не теряется между запусками.

## Защита денег

- Жёсткие лимиты из `config.yaml` проверяет **код, а не нейросеть**. ИИ может только ужесточить решение:
  - не больше 20% капитала в одной бумаге и 80% во всех акциях;
  - стоп-лосс не ближе 2 ATR и не дальше 8%, прибыль минимум в 1.5 раза больше риска;
  - дневной убыток 3%: новые покупки запрещены до завтра;
  - не больше 10 сделок в день, слабые сигналы не торгуются, шорта нет.
- Продажа своей позиции (выход из риска) разрешена всегда.
- Реальные деньги включаются только тремя действиями сразу: `broker: tinvest_live`,
  `live_trading_enabled: true` и флаг `--i-understand-real-money`, а потом нужно ещё ввести «ДА».

> ⚠️ Бот не гарантирует прибыль. ИИ ошибается, рынок непредсказуем. Сначала гоняйте бэктест
> и бумажную торговлю хотя бы несколько недель, а реальными деньгами торгуйте только той суммой,
> которую не жалко потерять.

## Установка

Нужен Python 3.10 или новее.

```bash
cd trading_bot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
cp .env.example .env               # и впишите ключи
```

## Запуск — по шагам

```bash
# 1. Демо без интернета и ключей: проверить, что всё работает
python main.py demo

# 2. Бэктест на реальной истории Мосбиржи (алгоритмы без ИИ, бесплатно)
python main.py backtest SBER GAZP --days 365

# 3. Анализ сейчас, без сделок: посмотреть, что думают агенты (с Claude)
python main.py analyze SBER

# 4. Бумажная торговля: реальные цены, виртуальные деньги (broker: paper)
python main.py run

# 5. Песочница Т-Инвестиций: реальный API брокера, виртуальные деньги
#    в config.yaml: broker: tinvest_sandbox, в .env: TINVEST_TOKEN
python main.py run

# Портфель и чему бот научился
python main.py status
```

Полезные флаги: `run --once` (один цикл), `run --no-llm` (без Claude), `run --ignore-hours` (не ждать открытия биржи).

## Сколько стоит Claude

Один цикл по одной бумаге — это 5–6 запросов к Claude (новостной агент пропускает запрос, если новостей нет).
Сколько потрачено, терминал показывает после каждого цикла. Чтобы тратить меньше:
увеличьте `poll_seconds`, уменьшите число тикеров или поставьте `llm_effort: low`.
Бэктест по умолчанию идёт без Claude: с ним каждая свеча стоит 5+ запросов.

## Подключение к бирже (когда будет доступ)

Брокер — **T-Invest API** Т-Банка (REST, `invest-public-api.tbank.ru`).

1. В приложении Т-Инвестиций: Настройки → Токены T-Invest API → создать токен.
   Для песочницы хватит токена только на чтение, для реальной торговли нужен токен с правом торговли,
   лучше ограниченный одним счётом.
2. Впишите токен в `.env` (`TINVEST_TOKEN=...`). В `config.yaml` или в git его не кладите.
3. Сначала `broker: tinvest_sandbox`: бот сам откроет счёт в песочнице и зачислит `start_cash`.

Стоп-лоссы бот проверяет сам на каждом цикле. **Пока бот выключен, стопы не работают**,
поэтому при реальной торговле ставьте страховочные стоп-заявки в приложении брокера.

## Структура

```
main.py              команды: demo, analyze, backtest, run, status
tbot/agents/         6 агентов
tbot/engine.py       конвейер одного цикла
tbot/memory.py       самообучение: точность агентов и уроки
tbot/brokers/        paper (виртуальный) и tinvest (песочница / реальный счёт)
tbot/data/           MOEX ISS (свечи, лента сделок), RSS-новости, синтетика для тестов
tbot/backtest.py     проверка на истории (исполнение по открытию следующей свечи)
tbot/terminal.py     вывод в консоль
tests/               pytest
```

Тесты: `python -m pytest -q tests`
