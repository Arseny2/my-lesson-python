# Торговый бот: 6 ИИ-агентов для акций Мосбиржи (T-Invest)

Бот торгует внутри дня: на минутных, 10-минутных или часовых свечах. Какой таймфрейм и какие акции
выгоднее, он решает сам по истории с учётом комиссий. Решение о каждой сделке принимает команда из 6 агентов
(схема из популярных роликов про «ИИ-хедж-фонд», за основу взят открытый проект TradingAgents):

| # | Агент | Что делает |
|---|-------|-----------|
| 1 | Технический аналитик | Свечи и индикаторы: EMA, SMA200, RSI, MACD, Боллинджер, ATR |
| 2 | Новостной аналитик | Новости компании и рынка (ЦБ, ставка, рубль, нефть) из RSS Интерфакса и РБК |
| 3 | Аналитик поведения трейдеров | Стакан (перевес покупателей/продавцов, «стены»), лента сделок, крупные игроки, страх и жадность |
| 4 | Бык и Медведь | Спорят о сделке, судья выбирает победителя и даёт итоговый сигнал |
| 5 | Трейдер | BUY / SELL / HOLD, размер, стоп-лосс, тейк-профит (с учётом комиссии) |
| 6 | Риск-менеджер | Последнее слово: урезает размер или запрещает сделку |

## Как это работает каждую минуту

1. Бот берёт из T-Invest API последнюю закрытую свечу, цену, стакан и ленту сделок. Данные без задержки.
2. Все 6 агентов сначала прогоняются **бесплатно**, на встроенных алгоритмах.
3. Если команда видит возможную сделку (сильный сигнал) или уже держит позицию, тот же прогон
   повторяется с **Claude**. Три аналитика спрашивают Claude одновременно, чтобы цикл уложился в минуту.
4. Claude тратит не больше `llm_daily_budget_usd × llm_budget_share` за сессию (по умолчанию половина
   дневного лимита) и равномерно распределяет бюджет на все 6 часов. Когда бюджет на текущий момент исчерпан,
   агенты продолжают работать на алгоритмах.
5. За 30 минут до конца сессии и незадолго до закрытия биржи бот закрывает все позиции.

## Как бот учится сам

- **Точность агентов.** Каждый сигнал через 5 циклов сверяется с реальным движением цены.
  Агенты, которые чаще угадывают, получают больший вес в голосовании.
- **Уроки сделок.** После закрытия позиции Claude разбирает сделку, и трейдер читает последние уроки.
- **Подбор стратегии** (`select`): бот сравнивает таймфреймы и пороги входа на истории.

## Защита денег (лимиты проверяет код, ИИ может только ужесточить)

- Дневной убыток **3%**: новые покупки запрещены до конца дня. Выход из позиции разрешён всегда.
- В одной сделке до стопа теряем не больше **1%** капитала: размер позиции считается от стопа.
- Тейк-профит должен быть хотя бы в 2 раза больше комиссии за вход и выход, иначе сделка запрещена.
- Стоп не ближе 2 ATR. Шорта нет, плеча нет.
- Реальные деньги включаются только так: `broker: tinvest_live` + `live_trading_enabled: true` +
  флаг `--i-understand-real-money` + ввести «ДА». Если `select` не нашёл прибыльной стратегии,
  реальная торговля не запустится (только с `--force`).

> ⚠️ **Про комиссию.** На тарифе «Инвестор» комиссия около 0.3% за сделку, то есть ~0.7% за вход и выход
> с проскальзыванием. Минутное движение акции обычно 0.05–0.2%, поэтому на минутках комиссия почти
> всегда съедает прибыль. Укажите свой тариф в `commission_pct`, и `select` честно покажет, что выгоднее.
> На тарифе «Трейдер» (~0.05%) у коротких сделок шансов больше.
>
> ⚠️ Бот не гарантирует прибыль. Сначала бумажная торговля и песочница, и только потом реальные деньги.

## Установка

Нужен Python 3.10 или новее.

```bash
cd trading_bot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
cp .env.example .env               # впишите ANTHROPIC_API_KEY и TINVEST_TOKEN
```

## Порядок запуска

```bash
# 0. Проверить, что всё установилось (без интернета и ключей)
python main.py demo

# 1. Подбор: какие акции по карману и какой таймфрейм прибыльнее (история Мосбиржи)
python main.py select

# 2. Посмотреть, что думают агенты прямо сейчас (с Claude, без сделок)
python main.py analyze

# 3. Бумажная сессия на 6 часов: реальные цены, виртуальные 1000 ₽
python main.py run --reset-paper

# 4. То же в песочнице Т-Инвестиций (broker: tinvest_sandbox в config.yaml)
python main.py run

# 5. Результаты и обучение
python main.py status
```

Полезные флаги `run`: `--hours 6`, `--once` (один цикл), `--no-llm`, `--verbose-cycles`,
`--ignore-hours` (не ждать открытия биржи).

## Сколько стоит Claude

Прогон с Claude — это 5–6 запросов на бумагу. Если звать Claude каждую минуту по 3 бумагам 6 часов подряд,
выйдет около 6000 запросов, что намного дороже капитала в 1000 ₽. Поэтому по умолчанию стоит режим
`escalate`: Claude подключается только в важные моменты и в пределах бюджета. Бюджет задаётся в долларах:
`llm_daily_budget_usd` (дневной лимит) и `llm_budget_share: 0.5` (за сессию тратится половина).
Сколько потрачено, терминал показывает каждый цикл.

## Подключение T-Invest

1. В приложении Т-Инвестиций: Настройки → Токены T-Invest API → создать токен.
   Для данных и песочницы хватит токена только на чтение. Для реальной торговли нужен токен
   с правом торговли, ограниченный одним счётом.
2. Впишите его в `.env` (`TINVEST_TOKEN=...`). Не кладите токен в `config.yaml` или в git.
3. Сначала `broker: tinvest_sandbox`: бот откроет счёт в песочнице и зачислит `start_cash`.

Стоп-лоссы бот проверяет сам каждую минуту. Пока бот выключен, стопы не работают,
но по умолчанию он и не оставляет позиций после конца сессии.

## Структура

```
main.py                   команды: demo, select, analyze, backtest, run, status
tbot/agents/              6 агентов
tbot/engine.py            цикл: бесплатный прогон -> (если стоит того) прогон с Claude -> заявка
tbot/strategy_select.py   подбор бумаг и таймфрейма с проверкой вне выборки
tbot/memory.py            самообучение: точность агентов и уроки
tbot/llm.py               Claude + бюджет с равномерным расходом
tbot/brokers/             paper (виртуальный) и tinvest (песочница / реальный счёт)
tbot/data/                T-Invest (реальное время), MOEX ISS (история), RSS-новости, синтетика
tbot/backtest.py          проверка на истории (исполнение по открытию следующей свечи)
tests/                    pytest: python -m pytest -q tests
```
