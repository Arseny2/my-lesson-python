# Как запустить бота на своём компьютере

## 1. Установите Python (один раз)

1. Скачайте Python 3.12 с https://www.python.org/downloads/
2. **Windows:** в первом окне установщика поставьте галочку **«Add Python to PATH»**, затем Install Now.
3. **Mac:** откройте скачанный файл .pkg и нажмите «Продолжить» до конца.

## 2. Скачайте бота

Бот лежит в ветке `claude/new-session-a73237` репозитория `Arseny2/my-lesson-python`.

- **Проще всего — архивом:**
  https://github.com/Arseny2/my-lesson-python/archive/refs/heads/claude/new-session-a73237.zip
  Распакуйте архив и откройте в нём папку `trading_bot`.
- **Или через git:**
  ```bash
  git clone -b claude/new-session-a73237 https://github.com/Arseny2/my-lesson-python.git
  cd my-lesson-python/trading_bot
  ```

## 3. Запустите

- **Windows:** двойной клик по файлу **`start_windows.bat`**.
- **Mac / Linux:** откройте Терминал в папке `trading_bot` и выполните `bash start_mac_linux.sh`.

Первый запуск сам установит библиотеки (1–3 минуты). Потом откроется меню:

```
  1  Настройка и проверка связи (токен T-Invest)
  2  Подобрать акции и таймфрейм по истории (select)
  3  Бумажная торговля 6 часов с нуля (1000 ₽ виртуально)
  4  Продолжить бумажную торговлю (без сброса счёта)
  5  Что думают агенты прямо сейчас (без сделок)
  6  Портфель, результаты и чему бот научился
  7  Демо без интернета
  0  Выход
```

## 4. Порядок действий

1. **Пункт 7 (Демо)** — проверить, что всё установилось. Интернет не нужен.
2. **Пункт 1 (Настройка)** — вставить токен T-Invest. Бот проверит связь с Мосбиржей,
   новостями и Т-Инвестициями и напишет, что работает (✓), а что нет (✗).
   - Токен: приложение Т-Инвестиций → Настройки → **Токены T-Invest API** → Создать →
     тип **«Только для чтения»**.
   - Токен вставляется в окно программы (символы не видны — так и должно быть).
     **Никому его не отправляйте, в чат тоже.**
   - Без токена бот тоже работает, но берёт цены с задержкой ~15 минут.
3. **Пункт 2 (Подбор)** — бот проверит на истории, какие акции по карману и какой таймфрейм
   (минутки, 10 минут или час) выгоднее. Займёт несколько минут.
4. **Пункт 3 (Бумажная торговля)** — 6 часов торговли виртуальными 1000 ₽ по реальным ценам.
   Биржа работает по будням 10:00–18:40 и 19:05–23:50 по Москве. Остановить можно Ctrl+C,
   тогда бот закроет позиции.
5. **Пункт 6** — посмотреть результат.

Пришлите результаты пунктов 2 и 6 (таблицы из окна) — по ним решим, что настраивать дальше.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «Python не найден» | Переустановите Python с галочкой «Add Python to PATH» и перезагрузите компьютер |
| «Не удалось установить библиотеки» | Проверьте интернет, запустите снова |
| «T-Invest: токен неверный» | Создайте новый токен и снова выберите пункт 1 |
| «Мосбиржа недоступна» | Проверьте интернет; иногда помогает выключить VPN |
| «сначала запустите select» | Выберите пункт 2 |
