# Торговый бот: 6 ИИ-агентов для акций Мосбиржи (T-Invest)

Схема из открытого проекта **TradingAgents**: команда аналитиков, спор Быка и Медведя, трейдер и риск-менеджер.
Его слабые места исправлены, а сам бот сделан для внутридневной торговли российскими акциями через Т-Инвестиции.

| # | Агент | Что делает |
|---|-------|-----------|
| 1 | Технический аналитик | Свечи и индикаторы: EMA, SMA200, RSI, MACD, Боллинджер, ATR |
| 2 | Новостной аналитик | Новости компании и рынка (ЦБ, ставка, рубль, нефть) из RSS Интерфакса и РБК |
| 3 | Аналитик поведения трейдеров | Стакан (перевес покупателей/продавцов, «стены»), лента сделок, крупные игроки, страх и жадность |
| 4 | Бык и Медведь + судья | Спорят о сделке (1 запрос или настоящие раунды), судья выносит сигнал |
| 5 | Трейдер | BUY / SELL / HOLD, размер, стоп-лосс, тейк-профит с учётом комиссии |
| 6 | Риск-менеджер | Совещание трёх риск-аналитиков (агрессивный, нейтральный, осторожный) и жёсткие лимиты в коде |

Плюс **память похожих ситуаций**: это не агент-мнение, а факты из прошлого — «в 20 похожих случаях цена
росла 14 раз, в среднем +0.3%».

## Чем лучше TradingAgents

| Проблема TradingAgents | Как решено здесь |
|---|---|
| Риск-контроль — только спор нейросетей, жёстких лимитов нет | Три взгляда риск-аналитиков, как у них, **плюс** лимиты в коде. ИИ не может их ослабить |
| Нет понимания «а есть ли у нас преимущество»: торгует всегда | Бот меряет свою точность. Если угадывает не лучше монетки, новых сделок нет |
| Комиссии не учитываются в решении | Сделка запрещена, если ожидаемое движение (по похожим ситуациям) меньше комиссии и проскальзывания |
| Память — последние решения и уроки | Поиск **похожих ситуаций** по 9 признакам и уроки из похожих ситуаций, а не просто последние |
| Веса аналитиков не меняются | Вес агента растёт с его точностью (до ×3) и падает до ×0.1, если он ошибается |
| $0.5–2 за одно решение, медленно, только дневки | Каждую минуту работают бесплатные алгоритмы, Claude — в важные моменты и в рамках бюджета. Аналитики спрашивают Claude параллельно |
| Если API упал, решения нет | Каждый агент переходит на свой алгоритм |
| Бэктест с ИИ может «вспомнить» историю из обучения модели | В бэктесте названия бумаг и даты от Claude скрыты |
| Решение разбирается из свободного текста | Строгие схемы ответов (structured outputs) |
| Только биржа-симулятор | Реальные заявки через T-Invest API (песочница и боевой счёт) |
| Данные США (Yahoo, Reddit) | Мосбиржа: T-Invest в реальном времени, MOEX ISS для истории, русские новости |
| Не работает в Windows без WSL | Чистый Python, работает везде |

## Проверка: умеет ли бот не терять деньги там, где нечего ловить

Минутные синтетические цены, по 3 прогона, комиссия 0.05%, капитал 1000 ₽:

| Рынок | Результат бота | Сделок | Прибыльных |
|---|---|---|---|
| Случайные цены (предсказать нельзя) | от 0% до −1% | 0–8 | — |
| Слабая закономерность (меньше комиссии) | от −1.3% до +0.6% | 22–29 | 38–64% |
| Сильная закономерность | **от +11% до +13%** | 141–150 | 77–84% |

До добавления этих защит бот на случайных ценах терял 8–10%. **Важно:** это синтетика.
Есть ли закономерности на реальном рынке, покажет только `python main.py select` на настоящей истории.

## Защита денег (лимиты проверяет код, ИИ может только ужесточить)

- В одной сделке до стопа теряем не больше **3%** капитала (30 ₽ из 1000). Размер позиции считается от стопа.
- Страховка на день: после убытка 9% (≈3 стопа) новые покупки запрещены до завтра.
- Тейк-профит хотя бы в 2 раза больше комиссии, стоп не ближе 2 ATR. Шорта и плеча нет.
- Выход по времени: позиция живёт не дольше 10 свечей, если сигнал ослаб.
- Реальные деньги включаются только так: `broker: tinvest_live` + `live_trading_enabled: true` +
  флаг `--i-understand-real-money` + ввести «ДА». Если `select` не нашёл прибыльной стратегии,
  реальная торговля не запустится.

> ⚠️ Проверьте условия тарифа «Трейдер» в приложении: если у него есть ежемесячная плата,
> при капитале 1000 ₽ она может оказаться больше любой прибыли.
>
> ⚠️ Бот не гарантирует прибыль. Сначала бумажная торговля и песочница, потом реальные деньги.

## Установка и запуск

**Пошаговая инструкция для своего компьютера — в файле [КАК_ЗАПУСТИТЬ.md](КАК_ЗАПУСТИТЬ.md).**
Коротко: Windows — двойной клик по `start_windows.bat`, Mac/Linux — `bash start_mac_linux.sh`.
Откроется меню; токен T-Invest вводится в пункте «Настройка».

Для тех, кто привык к командной строке:

```bash
cd trading_bot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py setup                # токен T-Invest и проверка связи
python main.py select               # какие акции по карману и какой таймфрейм прибыльнее
python main.py run --reset-paper    # бумажная сессия 6 часов: реальные цены, виртуальные 1000 ₽
python main.py status               # результаты и чему бот научился
python main.py demo                 # проверка без интернета
```

Другие флаги `run`: `--hours 6`, `--once`, `--verbose-cycles`, `--ignore-hours`.
Сейчас бот работает **без Claude** (`use_llm: false`): все агенты думают встроенными алгоритмами.
Когда появится ключ API, впишите `ANTHROPIC_API_KEY` в `.env` и поставьте `use_llm: true` в `config.yaml`.

## Бюджет на Claude

Каждый запрос к Claude платный (отдельный API-ключ, подписка Claude Pro/Max для бота не подходит).
`llm_daily_budget_usd: 10` — дневной лимит, `llm_budget_share: 0.5` — за сессию бот тратит не больше половины,
равномерно на все 6 часов. Claude подключается при сильном сигнале или открытой позиции.
В остальное время, и когда бюджет на текущий момент исчерпан, агенты работают на алгоритмах.
Расход виден в терминале каждый цикл.

`debate_rounds: 2` включает настоящий спор в раундах, как в TradingAgents (5 запросов вместо 1).
Это имеет смысл для 10-минутных и часовых свечей.

## Подключение T-Invest

1. Приложение Т-Инвестиций → Настройки → Токены T-Invest API → создать токен.
   Для данных и песочницы хватит токена только на чтение. Для реальной торговли нужен токен
   с правом торговли, ограниченный одним счётом.
2. Впишите токен в `.env` (`TINVEST_TOKEN=...`). Не кладите его в `config.yaml` или в git.
3. Сначала `broker: tinvest_sandbox`: бот откроет счёт в песочнице и зачислит `start_cash`.

## Структура

```
main.py                   команды: demo, select, analyze, backtest, run, status
tbot/agents/              6 агентов
tbot/engine.py            цикл: бесплатный прогон -> (если стоит того) Claude -> заявка; выход по времени
tbot/memory.py            точность агентов, похожие ситуации, уроки
tbot/strategy_select.py   подбор бумаг и таймфрейма с проверкой вне выборки
tbot/llm.py               Claude + бюджет с равномерным расходом
tbot/brokers/             paper (виртуальный) и tinvest (песочница / реальный счёт)
tbot/data/                T-Invest (реальное время), MOEX ISS (история), RSS-новости, синтетика
tbot/backtest.py          проверка на истории (исполнение по открытию следующей свечи)
tests/                    pytest: python -m pytest -q tests
```
